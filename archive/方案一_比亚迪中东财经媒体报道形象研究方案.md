# 方案一：基于语料库的中东财经媒体对中国新能源汽车品牌形象的建构研究
## ——以比亚迪在海湾国家的报道为例

---

## 1. 选题背景与研究价值

近年来，中国新能源汽车加速出海，中东（尤其是海湾合作委员会 GCC 国家）成为重要增量市场。比亚迪（BYD）较早布局阿联酋、沙特、卡塔尔等国，销售网络与品牌活动持续扩张。与此同时，海湾主流财经媒体对比亚迪的报道呈现出“技术—价格—安全—售后—文化”等多维话语，其中不乏因宗教文化差异产生的形象误读。

本研究以比亚迪为个案，构建海湾财经媒体多语种报道语料库，结合**媒介框架理论**与**语料库辅助话语研究（CADS）**，考察媒体如何建构中国新能源品牌在中东的形象。研究兼具理论价值与现实意义：
- 理论层面：将框架理论与语料库方法结合，丰富“中国品牌国际形象”的媒介话语研究；
- 现实层面：为中国车企的中东本地化传播、跨文化营销策略提供实证依据。

## 2. 新颖性检索结果与差异化定位

| 近邻研究 | 研究对象 | 与本研究差异 |
|---------|---------|-------------|
| Research on the International Corporate Image of Chinese Auto Enterprises Based on the NOW Corpus: Taking BYD as an Example | 全球英文新闻语料库中的比亚迪**企业**形象 | 非中东，非海湾财经媒体，非产品品牌形象 |
| 《比亚迪英文宣传片的多模态翻译及品牌形象构建研究》 | 比亚迪企业宣传片 | 官方话语，非新闻报道 |
| 《“一带一路”背景下，比亚迪的出海战略研究》 | 企业出海战略 | 管理学视角，非媒介话语/语料库 |
| 《A Corpus-based Study of Huawei's Image in British and ...》 | 华为在英美媒体形象 | 对象不同，地区不同 |

**差异化定位**：
1. 地域聚焦：海湾国家（GCC）财经媒体，而非全球媒体；
2. 对象聚焦：新能源**产品品牌**形象，而非企业形象；
3. 方法整合：多语种语料库 + 情感分析 + LDA + 批判话语分析；
4. 议题聚焦：跨文化营销中的宗教/文化“误读”个案。

**结论**：目前尚无以“海湾财经媒体报道 + 比亚迪产品品牌 + 语料库方法”为核心的研究，选题新颖性成立。

## 3. 研究问题

1. 海湾财经媒体如何报道比亚迪？报道的高频主题与话语框架是什么？
2. 报道情感倾向总体如何？是否存在“廉价—低质”刻板印象？
3. 媒体建构的比亚迪品牌形象包含哪些核心维度（技术、价格、安全、售后、环保、政策、文化等）？
4. 报道中是否因宗教/文化差异产生形象“误读”？如有，典型案例是什么？
5. 比亚迪官方品牌叙事与媒体重构叙事之间存在何种差异？

---

## 4. 理论框架

| 理论 | 应用方式 |
|------|---------|
| 媒介框架理论（Framing Theory） | 识别报道框架类型：技术领先、价格优势、环境可持续、安全风险、文化冲突等 |
| 语料库辅助话语研究（CADS） | 用词频、搭配、情感、LDA 揭示话语模式，再进行定性话语分析 |
| 品牌形象学 / 跨文化形象建构（Imagology） | 解释媒体如何“他者化”中国品牌，以及文化误读的生成机制 |

**理论组合优势**：成熟、应用型强，不需要重新发明理论，符合“理论应用相结合、难度适中”的要求。

### 5.1 替代路径

由于无法使用 Factiva/Nexis Uni 等商业数据库，采用以下组合策略：

| 路径 | 用途 | 工具/方法 |
|------|------|----------|

## 6. 语料库构建

### 6.1 字段设计

| 字段 | 说明 |
|------|------|
| id | 唯一编号 |
| title | 标题 |
| source | 媒体名称 |
| country | 所属国家 |
| date | 发布日期 |
| language | en / ar |
| url | 原文链接 |
| text | 正文纯文本 |
| word_count | 词数 |
| theme_tags | 主题标签（技术/价格/安全/售后/环保/政策/文化/宗教） |
| sentiment | 后续情感分析结果 |
| framing | 后续框架标注结果 |

### 6.2 数据清洗流程

1. 去重（标题+日期+正文哈希）
2. 去 HTML 标签、脚本、广告
3. 
4. 去除“相关推荐”“阅读更多”等噪声
5. 英文：spaCy 分词、停用词过滤
6. 阿拉伯语：camel-tools / AraBERT tokenizer、停用词过滤
7. 保留原文与清洗后文本双备份

### 6.3 人工标注

随机抽取 10–15% 样本进行双人标注：
- 主题标签：技术、价格、安全、售后、环保、政策、文化、宗教
- 情感极性：正面 / 中性 / 负面
- 框架类型：技术领先、价格优势、环境可持续、安全风险、文化冲突、其他

标注一致性用 Cohen's Kappa 检验，Kappa ≥ 0.7 为可接受。

## 7. 分析方法与技术路线

```text
数据清洗
    ↓
词频统计 + 关键词共现网络
    ↓
搭配分析（MI / Z-score）
    ↓
情感分析（VADER 英文 / AraBERT 阿语）
    ↓
LDA 主题建模（识别报道维度）
    ↓
批判话语分析（深度解读“误读”个案）
    ↓
框架归纳 + 形象类型化
    ↓
官方叙事 vs 媒体叙事对比
```

### 7.1 具体工具

| 环节 | 工具 |
|------|------|
| 爬虫 | Python requests / BeautifulSoup / Playwright |
| 英文 NLP | spaCy、NLTK、VADER |
| 阿语 NLP | camel-tools、AraBERT |
| 搭配与词频 | AntConc / Python 自定义脚本 |
| 主题建模 | Gensim LDA / sklearn LatentDirichletAllocation |
| 情感分析 | VADER / transformers(AraBERT) |
| 可视化 | matplotlib、seaborn、pyecharts、NetworkX |
| 话语分析 | NVivo / 人工编码 |

### 7.2 预期分析产出

1. 海湾财经媒体报道比亚迪的高频主题与搭配网络图
2. 情感倾向时序变化图
3. LDA 主题分布及代表性词汇表
4. “文化误读”典型个案清单（如宗教避讳、斋月用车、女性用户设计等）
5. 官方话语 vs 媒体话语的差异对比表

## 11. 风险与应对

| 风险 | 应对 |
|------|------|
| 中东媒体反爬/屏蔽 | 使用 headers、代理池、降低抓取频率；优先使用官网 RSS |

| 创新性被质疑 | 明确限定“海湾财经媒体 + 产品品牌 + 语料库”边界 |
| 分析复杂度过高 | 先完成英文主体分析，阿语部分可作为单独小节 |
