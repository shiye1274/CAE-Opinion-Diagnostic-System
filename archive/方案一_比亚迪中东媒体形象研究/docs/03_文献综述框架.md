# 文献综述框架

---

## 一、综述结构

### 1.1 引言（500–800 字）

**功能**：交代研究背景、问题来源、研究目的。

**写作要点**：
- 中国新能源汽车出海中东的现实背景（可引用行业数据）；
- 中东媒体在塑造中国品牌形象中的作用；
- 现有研究的不足（引出本研究的意义）；
- 研究问题与论文结构。

---

### 1.2 中国新能源汽车品牌国际化研究（1500–2000 字）

**功能**：梳理中国车企出海与品牌国际化文献。

**核心文献方向**：
1. 中国品牌国际化战略研究
2. 中国车企海外市场进入模式与本地化
3. 新能源汽车品牌传播与形象建构
4. "一带一路"框架下的中国企业海外形象

**关键问题**：
- 中国品牌在海外面临哪些传播挑战？
- 品牌国际化理论在新能源汽车领域的应用？
- 中东市场对中国品牌的态度与认知研究？

**代表性研究/学者**：
- 品牌国际化理论（如 Aaker 的品牌资产模型）
- 中国企业海外形象研究
- 新能源汽车出海战略分析

---

### 1.3 中东媒体话语与中国形象研究（1500–2000 字）

**功能**：梳理中东媒体如何报道/建构中国形象。

**核心文献方向**：
1. 中东媒体中的中国形象研究
2. 海湾国家媒体话语分析
3. 阿拉伯媒体与中国关系
4. 跨文化媒体框架与国家形象

**关键问题**：
- 中东主流媒体如何报道中国？
- 海湾国家媒体对中国经济/技术报道的框架？
- 阿语媒体与英语媒体的叙事差异？

**代表性研究**：
- 阿拉伯国家媒体中的中国形象研究
- 海湾媒体话语分析
- 中东-中国媒体互动研究

---

### 1.4 语料库辅助话语研究（CADS）（1500–2000 字）

**功能**：梳理语料库方法在话语分析中的应用。

**核心文献方向**：
1. 语料库语言学方法论
2. CADS 在媒体话语中的应用
3. 语料库辅助的品牌/形象研究
4. 多语种语料库研究

**关键问题**：
- CADS 如何揭示媒体话语模式？
- 语料库方法与话语分析的结合路径？
- 多语种语料库的构建与比较？

**代表性理论/学者**：
- John Sinclair（语料库语言学）
- Michael Baker, Paul Hardie, Tony McEnery（CADS）
- 玛丽亚·佩雷斯（批判话语分析与语料库）
- 现有 CADS 在新闻媒体中的应用研究

---

### 1.5 媒介框架理论（1500–2000 字）

**功能**：梳理框架理论及其在媒体话语研究中的应用。

**核心文献方向**：
1. 框架理论的发展（Goffman, Entman, Scheufele 等）
2. 框架在新闻报道中的应用
3. 框架分析方法
4. 品牌/产品框架研究

**关键问题**：
- 框架如何影响受众对报道对象的理解？
- 框架分析的操作化方法？
- 品牌框架与国家/企业形象的关系？

**代表性理论/学者**：
- Erving Goffman（框架分析）
- Robert Entman（框架定义与效果）
- Dietram Scheufele（框架建构与效果）
- 品牌框架与媒体框架研究

**功能**：总结现有研究，指出缺口，引出本研究定位。

## 三、写作注意事项

1. **文献要有批判性**：不要简单罗列，要评价现有研究的贡献与不足；
2. **逻辑递进**：从大背景（品牌国际化）到具体（中东媒体+新能源汽车）到方法（CADS+框架理论）；
3. **明确研究缺口**：最后必须清楚指出本研究填补的空白；
4. **引用规范**：APA/MLA/GB/T 7714 根据目标期刊要求；
5. **中英文文献兼顾**：既有中文品牌国际化研究，也有英文中东媒体研究。
