# 方案一：比亚迪/特斯拉中东媒体形象比较研究

本项目旨在通过多语种语料库方法，比较分析**比亚迪（BYD）**与**特斯拉（Tesla）**在海湾国家（GCC）媒体中的品牌形象建构。

## 项目目标

1. **学术目标**：完成一篇高质量期刊论文（中文或英文）
2. **竞赛目标**：完成大挑国奖参赛报告与可展示成果
3. **应用目标**：提炼面向中国新能源车企的品牌传播策略建议

## 快速开始

1. 安装 Python 依赖：`pip install -r scripts/requirements.txt`
2. 运行试采：`python scripts/collect_media.py --pilot`
3. 填写试采记录表：查看 `data/templates/媒体试采证据表.csv`
4. 根据试采结果决定是否调整媒体清单和检索式

## 研究设计概览

| 项目 | 内容 |
|------|------|
| 研究对象 | BYD vs Tesla 在中东媒体中的形象建构 |
| 研究时段 | 2020年1月 – 2025年12月 |
| 研究区域 | 海湾国家（UAE、沙特、卡塔尔等） |
| 语料语言 | 阿拉伯语 + 英语 |
| 目标语料 | 约700篇（BYD 300 + Tesla 400） |
| 主要方法 | 框架分析 + 语料库辅助话语研究 |

## 关键原则

1. **数据先行**：14天试采验证语料可得性
2. **人工为主，机器为辅**：人工框架编码是核心方法
3. **对照设计**：品牌、语言、媒体层级多维对照
4. **证据闭环**：每个结论都有可追溯证据
