# 爬取任务分工与交接文档（A/B 双人版）

> 目标：把 collector 框架和爬取目标拆成两份互不冲突的工作包，一人一半。
> 前提阅读：`docs/爬取框架方案.md`（10 分钟）、`collector/README.md`（5 分钟）

---

## 一、交接前你需要完成的 6 个步骤（按顺序）

### 步骤 1：建 Git 仓库并推送（30 分钟）
```bash
cd D:\桌面\语料库论文
git init
git add .          # .gitignore 已排除 corpus/raw、*.sqlite、审计日志等大文件
git commit -m "init: collector framework v0.1"
# GitHub 建私有仓库 middle-east-brand-sentinel，推送
git remote add origin https://github.com/<你的用户名>/middle-east-brand-sentinel.git
git push -u origin main
```
- 邀请组员为 Collaborator（Settings → Collaborators → Add people）
- **大文件不进 Git**：corpus/raw 原始数据走网盘同步（见步骤 5）

### 步骤 2：确认组员环境能跑通（15 分钟验收）
让组员在自己电脑执行，**这两条命令全部成功才算交接完成**：
```bash
pip install -r requirements.txt
python run_trial.py --dry-run     # 应打印 618 个查询组合，不联网
```
组员需具备：Python 3.10+、能访问 Google/GDELT/Reddit/YouTube（校园网环境见步骤 4 的坑）。

### 步骤 3：在 sources.yaml 划分认领边界（10 分钟）
给每个源加 `owner: A` 或 `owner: B` 字段（分工表见第二节）。
改完提交：`git commit -am "assign owners"`。**此后每人只改自己 owner 的源条目**（核验 search_url 后回写），避免 Git 冲突。

### 步骤 4：约定限流错峰规则（关键坑，5 分钟）
- **GDELT 限流是按 IP 算的**：如果两人连同一个校园网 WiFi，同时跑 GDELT 会互相 429！
- 规则：GDELT 只由 A 负责（夜批）；B 不跑 GDELT 通道（`--no-gdelt`）。
- 同一源不要两人同时抓（各自 owner 隔离已避免）。

### 步骤 5：约定数据回传与合并流程（10 分钟）
| 事项 | 约定 |
|---|---|
| 回传内容 | 各自 `corpus/raw/<自己的源ID>/` 目录打包 |
| 命名规范 | `corpus_raw_<owner>_<日期>.zip`，如 `corpus_raw_B_20261124.zip` |
| 传输方式 | 网盘/OneDrive/微信文件均可 |
| 频率 | 每周一次（周日晚） |
| 合并入库 | **由 A 统一执行**：把 B 的 raw 包解压进自己的 `corpus/raw/`，跑 `python pipeline.py`，SQLite 库以 A 的机器为准 |
| 审计日志 | B 每周连同 `collector/audit/run_*.jsonl` 一起回传（可复现凭证） |

### 步骤 6：定义验收标准（每周例会对照）
| 指标 | A 份额 | B 份额 |
|---|---|---|
| 一期目标（3,000 篇 + 9,500 UGC）中的分摊 | 长文 ≥1,600 篇 | 长文 ≥1,400 篇 + UGC ≥9,500 条 |
| search_url 核验完成度 | 自己源 100% | 自己源 100% |
| 阿语占比总目标 ≥45% | 阿语源全在 A，天然达标 | 不用背这个指标 |

## 三、组员上手指南（可直接转发）

```text
【第 1 天】
1. 装 Python 3.10+ 和 Git
2. 克隆仓库：git clone https://github.com/<你>/middle-east-brand-sentinel.git
3. cd collector && pip install -r requirements.txt
4. 验证：python run_trial.py --dry-run   （打印 618 个查询 = 环境OK）
5. 通读 collector/README.md

【日常流程（每天约 10 分钟）】
1. git pull（拿到最新词包）
2. python run_trial.py --no-gdelt --max-per-query 5      # Google News 增量
3. python run_trial.py --no-gdelt --no-gnews --sources <今天负责的源> --max-per-query 10
4. 核验 sources.yaml 里属于你的源：打开 search_url 试一下能否搜索，
   能 → 把 verify: true 改成 false 并回填 search_url；不能 → 保留 true，在群里报
5. git add collector/sources.yaml && git commit -m "verify: xxx" && git push
6. 周日晚：打包 corpus/raw/ 你的目录 + audit/ 日志 → 网盘 → 群里通知

【红线】
- 不要跑 GDELT（A 独占，限流按 IP，两人同跑会互相封）
- 不要改别人 owner 的源条目
- 不要把 corpus/raw 传到 Git（.gitignore 已挡，别强行 -f）
```
