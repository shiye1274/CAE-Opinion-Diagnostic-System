# L1 政策层补采方案

> 目标：把 L1 层从当前 **0 条** 提升到 **≥200 条**，覆盖沙特、阿联酋、卡塔尔、科威特等海湾国家的官方政策/愿景/标准发布，作为“政策-媒体-评论”五层结构的顶层锚点。

## 1. 现状问题

`sources.yaml` 中已有 7 个 L1 源，但 `adapter: manual`，意味着没有自动采集：

- `vision2030`（沙特 2030 愿景）
- `uae_moei`（阿联酋能源与基建部）
- `saso`（沙特标准局 EV 准入）
- `kahramaa`（卡塔尔 Tarsheed）
- `kapsarc`（KAPSARC 能源智库）
- `agsiw`（AGSIW 海湾智库）
- `carnegie_me`（Carnegie 中东）

后三者（智库）严格说属于 L1.5 政策研究，但方案中可并入 L1。

## 2. 采集策略

### 2.1 通道选择

| 通道 | 适配器 | 优点 | 风险 |
|---|---|---|---|
| **官网 RSS/Newsroom** | `rss_native` | 官方、可回源、文本规范 | 很多政府站无 RSS |
| **官网站内搜索** | `SiteSearchAdapter` | 直接命中政策新闻 | 搜索接口不标准，需逐个验证 |
| **GDELT/Google News** | 现有适配器 | 覆盖广 | 对政府站索引慢，标题级多 |
| **PDF/HTML 解析** | 新增 `pdf_html_adapter` | 官方发布多为 PDF/网页 | 需处理 PDF 下载和 OCR |

## 3. 关键适配器实现

### 3.1 政府站内搜索适配

多数政府站搜索 URL 不标准，需要逐个验证。通用模式：

```yaml
- id: vision2030
  adapter: site_search
  search_url: "https://www.vision2030.gov.sa/news/?search={q}"
  config:
    content_selector: "article"   # 正文 selector
    list_selector: "a[href*='/news/']"
```

### 3.2 PDF/HTML 政策文档解析（新增 `pdf_html_adapter.py`）

如果政策发布为 PDF：

```python
class PDFHTMLAdapter:
    def follow_article(self, url):
        if url.endswith(".pdf"):
            # 下载 PDF -> pdfplumber / PyMuPDF 提取文本
            text = extract_pdf_text(url)
        else:
            # 复用 SiteSearchAdapter.extract_text
            text = extract_text(html)
        # 发布日期从 URL 或 meta 提取
        # 如 https://www.vision2030.gov.sa/media/2024/01/report.pdf -> 2024-01
```

依赖：`PyMuPDF` 或 `pdfplumber`。

### 3.3 与现有 L1 源合并

把 `sources.yaml` 中 7 个 `adapter: manual` 的 L1 源改为实际适配器：
- 有 RSS 的改 `rss_native`；
- 有搜索页的改 `site_search`；
- PDF 归档的改 `pdf_html`；
- 仍无法自动化的保留 `manual`，并标记为“决赛前人工补 20 篇”。

## 5. 风险与兜底

| 风险 | 应对 |
|---|---|
| 政府站反爬/海外 IP 屏蔽 | 用 B 的代理/国内节点；限流 `rate ≤ 1.0` |
| 搜索接口返回首页/列表页 | 人工复核后改用 `channels: [gdelt, google_news]` |
| PDF 扫描版无文本层 | 用 OCR（Tesseract/PaddleOCR），标注 `lang_variant` |
| 政策文档多为英文/阿语，中文少 | 中文 L1 用新华社对中东政策的报道间接覆盖 |

## 6. 验收标准

- L1 总量 ≥ 200 条。
- 覆盖国家 ≥ 4 个（沙特、阿联酋、卡塔尔、科威特/巴林）。
- 每个 L1 源 ≥ 10 条。
- 政策发布日期字段完整率 ≥ 80%。
- PDF/HTML 均可回源到原始 URL。
