# 可穷尽多源爬取框架设计方案（collector v0.1）

> 依据：《挑战杯选题升级与多语种语料库建设完整规划(1)》表 3-2（五层 45+ 数据源）、表 3-4（四层数据字典）、表 7-2（14 天试采硬门禁）、表 7-3（风险 R1 反爬预案）
> 工程定位：配置驱动 · 多通道互补查全 · 全留痕可复现

---

## 一、设计原则

1. **检索词不写死在脚本里**：品牌词包 × 场景词包 × 国家词包全部放 YAML 配置进 Git，换课题只改配置不改代码。
2. **穷尽靠通道叠加，不靠单一爬虫**：同一个查询走 GDELT 全量索引 + Google News 聚合 + 站内搜索 + 存档回源四条通道，互相补漏。
3. **可复现靠留痕**：每次运行记录查询式、参数、时间戳、命中数、失败原因；每条语料保存 URL + 抓取时间 + 内容哈希 + 本地快照。
4. **合规红线**：不破解付费墙；UGC 100% 脱敏（用户名/ID 哈希化）；遵守 robots 与平台条款；抓取节奏限速。

## 二、查询穷尽矩阵

查询 = 词包笛卡尔组合，按通道语法渲染：

```
EntityPack(品牌中阿英锚点) × DomainPack(场景痛点词) × CountryPack(国家/城市)
```

| 通道 | 查询语法示例 | 作用 |
|---|---|---|
| GDELT 2.0 DOC API | `(BYD OR "بي واي دي") sourcelang:arabic (sourcecountry:SA OR ...)` | 全量新闻索引查全（主力） |
| Google News RSS | `https://news.google.com/rss/search?q=BYD+OR+Tesla&hl=ar&gl=SA&ceid=SA:ar` | 实时增量 + 小站兜底 |
| 站内搜索 | 各媒体 search URL 模板 | GDELT 未索引源 |
| YouTube (yt-dlp / Data API v3) | 关键词搜索 + 频道枚举 + 评论区 | L4/L5 多模态 |
| Reddit 公开 JSON | `reddit.com/search.json?q=BYD dubai` | L5 受众话语 |
| Wayback Machine | 死链/付费页历史快照回源 | 存档通道 |

### GDELT 实测注意事项（2026-11-17 冒烟测试结论，已固化进 gdelt_adapter.py）

1. **限流惩罚会累积**：官方说 5 秒/请求，实测连发多次后 30–60 秒仍 429。框架设 `rate=30s` + 429 指数长退避（30/60/90s）。全量跑一轮 GDELT 约 1 小时，适合夜间批处理。
2. **错误以 HTTP 200 + 纯文本返回**，必须检查响应体而非状态码。已实测到的错误文案：
   - `Queries containing OR'd terms must be surrounded by ().` → OR 查询必须加括号；
   - `The specified phrase is too short.` → 引号短语 ≥4 字符，短词（BYD/نيو）用裸词；
   - `Invalid/Unsupported Country.` → 国别代码无效时自动降级：去掉 sourcecountry 过滤重试（仍受 sourcelang 约束，查全不受影响）。
3. **国别代码需试采期逐个核验**（AE 已实测有效；SA/QA/KW/OM/BH 待确认），结果回写 `packs/countries.yaml`。

**词包滚动扩充（snowballing）**：pipeline 阶段对已入库文本跑实体识别，发现新品牌名/新源站即回填词包并记录到 `collector/audit/snowball_log.csv`。

## 三、源注册表（sources.yaml）

全部 L1–L5 数据源结构化成一条条记录，字段：

```yaml
- id: arabnews            # 源唯一 ID
  name: Arab News
  layer: L2               # 五层体裁
  language: en            # ar / en / zh
  country: SA
  adapter: site_search    # rss / gdelt / site_search / yt_dlp / youtube_api / reddit
  search_url: https://www.arabnews.com/search?q={q}   # null = 试采期人工核验
  verify: true            # URL 未核验标记，试采时确认
  rate: 1.5               # 请求间隔秒
  channels: [gdelt, google_news, site]   # 该源参与的查询通道
  note: 免费可爬；历史上的付费墙情况记录于此
```

> **核验机制**：所有直连 URL 标注 `verify: true`，试采首日由适配器探测并回写 `verify: false + last_checked 时间`；探测失败的自动降级到 Google News/GDELT 通道并在审计日志标记 `DEGRADED`。

## 四、数据流水线

```
采集(raw) → 清洗(clean) → 去重(dedup) → 语言/方言识别 → 脱敏(PII scrub)
   → 入库(SQLite 四表 + JSONL) → 质量报告(gates) → 审计日志(全程)
```

| 阶段 | 实现 | 说明 |
|---|---|---|
| raw 保存 | `corpus/raw/{source_id}/{yyyymmdd}/` | HTML/JSON/字幕原文 + `manifest.json`（URL、抓取时间、SHA256） |
| 清洗 | BeautifulSoup 正文抽取 + 样板噪音剔除 | 站点级 selector 可在 sources.yaml 覆盖 |
| 去重 | 规范化文本 SHA256 精确去重 + 8-gram SimHash 近似去重 | 跨源同稿（转载）会命中近似重复 |
| 语言识别 | 字符集启发（阿/中/英字符占比）+ langdetect 双校验 | 输出 ar / en / zh |
| 方言标记 | 海湾方言词表命中数 + Arabizi 正则 | 输出 MSA / Khaliji / Arabizi / EN / ZH |
| 脱敏 | 正则：邮箱、手机号、@用户名、URL 内用户名 | 用户 ID 一律哈希 |
| 入库 | SQLite `corpus/meta/corpus.sqlite` | 表结构对齐规划表 3-4：`corpus_documents` / `doc_entities` / `corpus_spans_annotations`（预留）/ `ugc_threads` |

## 五、复现性保障清单

| 机制 | 落地文件 |
|---|---|
| 词包/源配置版本化 | `collector/packs/*.yaml`、`collector/sources.yaml`（进 Git） |
| 运行审计日志 | `collector/audit/run_{run_id}.jsonl`（每条查询一行） |
| 试采证据日志 | `collector/audit/试采证据日志_{run_id}.csv` |
| 内容哈希 | 每条语料 `sha256` 字段 |
| 快照回源 | `archive_url`（Wayback）+ 本地 raw 快照 |
| 确定性去重 | 文本规范化规则版本号写入记录 `clean_ver` |

## 六、质量门禁（自动输出）

`run_trial.py` 结束自动生成门禁报告：

- 有效全文 ≥ 500 篇（`text_clean` 长度 ≥ 200 词）
- 覆盖媒体/平台 ≥ 15 家
- 阿语占比 ≥ 45%

未达标时报告列出缺口分解（按源 × 语言），指导补采方向。

## 七、风险预案（对齐规划表 7-3）

| 风险 | 框架内应对 |
|---|---|
| 反爬/付费墙（MEED、AGBI 等） | 降级 GDELT 元数据 + Google News 摘要 + Wayback 快照，不强攻 |
| X 平台 API 限流 | L5 重心放 YouTube API（免费配额）+ Haraj/Reddit 公开接口 |
| 方言噪音/水军 | pipeline 垃圾过滤器（全大写/表情比/URL 堆积阈值）+ Arabizi 转写 |
| 隐私合规 | 脱敏强制开启；raw 层保留但 processed 层输出前必须过 scrub |

## 八、目录

```
collector/
├── sources.yaml          # 源注册表（L1–L5 全量）
├── packs/                # 词包：brands_cn / brands_comp / context_mena / countries
├── adapters/             # 通道适配器
│   ├── base.py           # HTTP 会话/限速/重试/审计日志/原始落盘
│   ├── rss_adapter.py    # Google News RSS + 站点 RSS
│   ├── gdelt_adapter.py  # GDELT 2.0 DOC API（分页 + 时间窗）
│   ├── site_search.py    # 通用站内搜索（selector 可配置）
│   ├── yt_dlp_adapter.py # YouTube 搜索 + 字幕下载
│   ├── youtube_api.py    # YouTube Data API v3（评论区）
│   ├── reddit_api.py     # Reddit 公开 JSON
│   └── wayback.py        # 存档回源
├── pipeline.py           # 清洗→去重→语言→脱敏→入库
├── run_trial.py          # 试采编排器 + 门禁报告
├── audit/                # 运行日志与证据日志
└── requirements.txt
```
