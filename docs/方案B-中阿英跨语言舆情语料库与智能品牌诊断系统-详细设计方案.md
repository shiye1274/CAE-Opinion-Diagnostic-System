# 方案 B：中阿英跨语言舆情语料库构建与智能品牌诊断系统
## 详细设计方案（技术+工程+实施）

> 项目全称：《破壁中东：面向中国新质生产力出海的中阿英跨语言舆情语料库构建与智能品牌诊断系统》
> 参赛定位：大挑·哲社类（中国之治）或 科技发明制作 B 类（软件系统）
> 难度：中高 · 需较强 Python/NLP 与前端开发能力
> 版本：v1.0 · 编制日期：2026-11-17

---

## 一、项目定位与核心目标

### 1.1 背景与问题

随着中国新质生产力企业（新能源汽车、光伏、3C 智能硬件、跨境电商等）加速出海中东，品牌舆情管理面临三大痛点：

1. **语言壁垒**：中/阿/英三语舆情分散在不同平台，语义无法直接对齐比较；
2. **方言难题**：海湾阿拉伯语（沙特、阿联酋、卡塔尔、科威特等方言）与标准阿拉伯语（MSA）差异巨大，通用情感模型准确率低；
3. **合规风险**：宗教禁忌、政治敏感、性别表达、斋月营销等文化合规问题难以量化预警，一次失误可能引发品牌危机。

### 1.2 核心目标（三大交付物）

| # | 交付物 | 说明 | 验收标准 |
|---|---|---|---|
| ① | **中阿英跨语言对齐语料库** | 中/阿/英三语语义对齐、情感标注、主题标注的语料库（目标 3–5 万条高质量标注） | 标注一致率 κ ≥ 0.75；覆盖 ≥ 5 个中东国家 |
| ② | **LLM-as-Annotator 人机协同标注流水线** | 大模型预标 + 人工复核 + 主动学习迭代，将人工标注成本降低 60% 以上 | 单条标注平均耗时 ≤ 30 秒；预标准确率 ≥ 85% |
| ③ | **Web 舆情监测与文化合规审查原型** | 可交互系统：舆情大屏、品牌诊断报告、合规风险雷达 | 端到端响应 ≤ 3 秒；支持中/阿/英三语输入 |

### 1.3 创新点

1. **首个面向中国品牌出海中东的中阿英三语对齐舆情语料库**（填补数据空白）；
2. **海湾方言情感计算**：方言识别 → 方言规范化 → 方言情感模型三级流水线；
3. **LLM-as-Annotator 人机协同机制**：大模型预标 + 专家复核 + 主动学习，形成可复用的标注范式；
4. **文化合规量化审查**：将宗教/政治/性别/本地化等隐性文化风险转化为五维可计算指标。

## 三、技术栈明细

### 3.1 数据采集与预处理

| 模块 | 技术选型 | 说明 |
|---|---|---|
| 爬虫框架 | Scrapy、Playwright | 新闻/论坛静态+动态页面 |
| 平台 API | X API、YouTube Data API、Reddit API | 社交媒体公开数据 |
| 语言识别 | fastText langid + langdetect 双校验 | 中/阿/英三语识别准确率 > 98% |
| 阿语处理 | camel-tools、pyarabic、CAMeL 正规化 | 阿拉伯语分词、去变音符号、字母正规化 |
| 海湾方言识别 | 微调的 DialectID 分类器（基于 CAMeL Lab 方言语料 + 自建数据） | 区分 MSA / 海湾方言 / 埃及方言等 |
| 去重 | SimHash + MinHash | 近重复文本去除 |
| 敏感数据脱敏 | 正则 + NER | 用户名、手机号、个人信息脱敏，符合数据合规 |

### 3.2 核心模型与算法

| 任务 | 方案 | 备注 |
|---|---|---|
| 跨语言语义对齐 | `intfloat/multilingual-e5-large` 或 `BAAI/bge-m3`、LaBSE；对比学习微调（InfoNCE） | 中/阿/英三元组检索，Recall@10 目标 ≥ 0.80 |
| 方言规范化 | mT5 / AraT5 seq2seq，将海湾方言改写为 MSA | 再接情感/主题模型，降低方言干扰 |
| 情感计算（三语） | 阿语：MARBERTv2 / AraBERT 微调；中文：Chinese-RoBERTa；英文：RoBERTa | 方面级情感（ABSA）可选进阶 |
| 海湾方言情感 | 在 ArSAS + ASTD + 自建海湾方言标注集上继续预训练 + 微调 | 目标 F1 ≥ 0.80 |
| 文化合规审查 | 五维规则库（宗教/政治/性别/禁忌/本地化）+ LLM 判定 + 关键词/NER 校验 | 输出风险等级 + 依据片段 |
| LLM-as-Annotator | GPT-4o / Claude / Qwen2.5-72B 生成伪标签 + 置信度；低置信度进入人工复核池 | Prompt 含标注规范、few-shot 示例 |
| 蒸馏落地 | 人工复核后的高质量数据 LoRA 微调 Qwen2.5-7B，形成自有领域小模型 | 降低推理成本 |

### 3.3 后端工程

| 组件 | 选型 |
|---|---|
| Web 框架 | FastAPI + Pydantic v2 + Uvicorn |
| ORM/迁移 | SQLAlchemy 2.0 + Alembic |
| 任务队列 | Celery + Redis（beat 定时调度） |
| 鉴权 | JWT（OAuth2 Password Flow），标注员/审核员/管理员三级角色 |
| 向量检索 | FAISS（轻量）或 Milvus（可扩展） |
| 文档 | FastAPI 自动生成 OpenAPI/Swagger |

### 3.4 前端工程

| 组件 | 选型 |
|---|---|
| 框架 | React 18 + TypeScript + Vite |
| UI | Ant Design 5 |
| 可视化 | ECharts 5（时间线、热力图、雷达图、桑基图） |
| 地图 | ECharts GeoJSON（中东国家/城市下钻） |
| 状态管理 | Zustand |
| 请求 | Axios + 拦截器（自动 JWT、错误提示） |

### 3.5 基础设施

- 版本管理：Git + GitHub（分支策略：main / dev / feature-*）
- 容器化：Docker + docker-compose
- CI：GitHub Actions（lint + 单元测试 + 构建）
- 监控：结构化日志（loguru）+ 简易指标看板

## 五、实施进程（21 周里程碑计划）

### Phase 0 · 立项与调研（第 1–2 周）
- 确定赛道（哲社类 vs 软件系统类）与评审侧重点；
- 调研 10–15 个中国品牌出海中东案例（如某新能源车、某手机品牌）及其舆情事件；
- 收集中东社交平台生态、数据源清单与合规边界；
- 明确团队分工与开发环境（Git 仓库、代码规范、周会制度）。
- **产出**：立项书、数据源调研清单、分工表。

### Phase 1 · 数据采集与语料基座（第 3–6 周）
- W3：搭建爬虫框架与 API 客户端；确定关键词体系（品牌×国家×话题）；
- W4：清洗/去重/语言识别流水线；MongoDB 入库；
- W5：海湾方言识别分类器 v1（预训练方言 ID 模型 + 自建种子数据）；
- W6：语料规模达标（原始 ≥ 10 万条），建立数据质量报告。
- **产出**：原始语料库、采集调度任务、数据质量看板。

### Phase 2 · 标注体系与人机协同流水线（第 7–10 周）
- W7：制定三语标注规范（情感：正/中/负 + 强度；主题：产品/价格/服务/国别形象等；合规：五维风险）；
- W8：开发 LLM-as-Annotator 预标（Prompt 工程 + 少样本示例 + 置信度输出）；
- W9：标注平台（前端工作台 + 后端任务分发）上线，人工复核闭环跑通；
- W10：主动学习迭代（低置信度优先复核），一致性评测（Kappa）。
- **产出**：3–5 万条高质量标注语料、标注平台 v1、标注规范文档。

### Phase 3 · 模型研发（第 11–14 周）
- W11：跨语言对齐——e5/bge-m3 召回评测 + 对比学习微调；
- W12：海湾方言规范化（seq2seq）+ 方言情感模型微调；
- W13：文化合规审查引擎（规则库 + LLM 判定 + 案例校准）；
- W14：全链路评测（F1 / Recall@K / 合规误报率），蒸馏出轻量推理模型。
- **产出**：各任务模型 checkpoint、评测报告。

### Phase 4 · 系统开发与集成（第 15–18 周）
- W15：FastAPI 全部业务接口 + 前端路由骨架；
- W16：舆情大屏（时间线、情感分布、国别热力、话题聚类）；
- W17：品牌诊断报告生成（趋势解读 + 合规雷达 + 行动建议）+ 合规审查台；
- W18：端到端联调、性能优化（缓存、批量推理）、演示数据集准备。
- **产出**：可交互 Web 原型（内测版）。

### Phase 5 · 测试、论文与路演（第 19–21 周）
- W19：真实案例验证（选取 3 个品牌回溯历史舆情事件，验证系统预警/诊断有效性）；
- W20：论文/作品说明书撰写（问题—方法—数据—结论），录制约 3 分钟演示视频；
- W21：路演 PPT、答辩演练、系统稳定备份（离线演示方案兜底）。
- **产出**：参赛论文、演示视频、路演材料、可复现环境。

## 七、评测与验收指标

| 维度 | 指标 | 目标 |
