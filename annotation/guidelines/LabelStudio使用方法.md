# Label Studio 使用方法（部署版 + 标注员日常版）

> 配套文件：`标注入门指南.md`（先读那个学打标签，这个只讲操作）
> 版本：2026-11-19 ｜ 本地部署地址：`http://localhost:8080`

---

# 第一部分：队长部署（只做一次，约 15 分钟）

## 1. 启动服务

```powershell
cd D:\桌面\语料库论文\annotation
.venv\Scripts\label-studio start
```
> 关掉终端服务就停；长期演示可加 `--background` 参数。
> 首次启动会自动生成本地数据库（SQLite，零配置）。

## 2. 创建管理员账号（首次访问）

浏览器打开 `http://localhost:8080` → 首次进入注册页：
- 填你的邮箱 + 密码（本地部署不发验证邮件，随便填邮箱格式即可）
- 进入主界面

## 3. 建项目 + 导入标注配置

1. 左上角 **Create** → 项目名填 `GreenSilk 校准集`
2. 进入项目 → **Settings → Labeling Interface**（1.23.2 版名称，旧版叫 Labeling Setup）
3. 选择 **Code** 标签 → 粘贴 `annotation/guidelines/labelstudio_config.xml` 的全部内容 → **Save**
4. 预览应显示：正文区 + 右侧 8 个标注字段（品牌/角色/层级/框架/情感/方面/误读/备注）

## 4. 导入待标数据

1. 项目页 → **Import** → 上传 `corpus/processed/calibration_set.json`
2. 导入后列表应出现 C001…C092（或更多，视抽样数量）任务卡片
3. 确认每条任务的"标题/正文/语言"字段显示正常

## 5. 给标注员开账号

1. 左侧菜单 **Organization** → **Invite People**
2. 分别邀请两名标注员邮箱 → 角色选 **Annotator**（只能标，看不到对方结果）
3. 把地址+账号密码发给他们
   > 注意：Annotator 角色**互相看不到对方标注、不能导出**——这正是双盲需要的

## 6. 每周例行（队长）

| 动作 | 位置 |
|---|---|
| 查看进度 | 项目页顶部显示 completed/total |
| 导出双份 | 项目 → **Export → JSON**（分别在两名标注员各自完成若干后导出） |
| 算一致性 | 导出文件放到 `annotation/agreement/` → `python kappa.py a1.json a2.json` |
| 仲裁分歧 | κ 未达标时，把分歧样本标给第 3 人（Supervisor 角色）裁决 |

# 第二部分：标注员日常（每天照此操作）

## 1. 登录
浏览器打开 `http://localhost:8080` → 输入队长给的账号密码。

## 2. 开始标注
1. 进入项目 **GreenSilk 校准集** → 点第一个未完成任务
2. **左侧读原文**（阿语自动 RTL 显示）；读不懂就点右下 **Skip**（跳过不标比瞎标好）
3. **右侧按顺序打 8 个字段**（对照《标注入门指南》第二节）：

| 顺序 | 字段 | 操作 |
|---|---|---|
| ① | 品牌与角色 | 多选框，勾选文中出现的品牌 |
| ② | 主导中国品牌角色 | 单选 |
| ③ | 指涉层级 | 单选 |
| ④ | 主导框架 | 单选（11 选 1） |
| ⑤ | 次要框架 | 单选，没有就选"无" |
| ⑥ | 情感 5 级 | 单选 |
| ⑦ | 评价方面 | 多选，没有就选"无" |
| ⑧ | 文化误读 | 单选（6 选 1） |

4. **标了误读必须做两件事**：
   - 在原文里**高亮证据句**（点选"证据句"标签 → 拖选原文片段）
   - 下方文本框抄录证据句
5. 点 **Submit**（提交）。⚠️ 没有"保存草稿"概念，提交才算完成。

## 3. 快捷键（提升 50% 速度）

| 键 | 作用 |
|---|---|
| `1–9` | 快速选择右侧选项（按面板顺序） |
| `Ctrl + Enter` | 提交当前任务 |
| `↑ / ↓` | 上一个/下一个任务 |
| `空格` | 跳过（Skip）当前任务 |

## 4. 每天结束时

1. 回到项目列表确认自己完成数（页面顶部 `X completed`）
2. **不用导出**——队长统一导出
3. 遇到边界案例（手册没写的情况）：记到共享表格"边界案例"栏，周会统一裁决

## 5. 铁律（重复一遍）

- ❌ **绝不要**把自己的标注截图/告诉另一位标注员（破坏双盲，Kappa 作废）
- ❌ 看不懂不要猜 → Skip + 备注
- ✅ 不确定但接近 → 照指南的"常见疑问速查表"选
- ✅ 发现手册漏洞 → 记录反馈，你是手册 v2.1 的共建者

# 第三部分：常见问题

| 问题 | 解决 |
|---|---|
| 8080 打不开 | 问队长服务是否启动（`label-studio start` 是否在跑） |
| 忘记密码 | 队长在 Organization 里重置 |
| 阿语显示方块/乱码 | 浏览器确认 UTF-8；换 Chrome/Edge |
| 提交按钮是灰的 | 必填字段（主导框架/情感/误读）没选完 |
| 标错想改 | 已提交任务不能自改 → 找队长在 Review 区改 |
| 正文太短只有标题 | 属正常（全文回源进行中）→ 照标，可在 note 注明 "short_text" |
| 网页卡/断网 | 本地部署不会断网；刷新页面已提交的不会丢 |

# 附：数据流全景（标注数据从点选到进模型）

```
标注员点选 → Label Studio（界面，SQLite 存储）
   │ 队长每周 Export JSON
   ▼
转换脚本 → annotation/data/*.json（权威层，按 annotation_schema.json 校验）
   │  ├─ annotations.a1 / a2 双盲键 → kappa.py 算一致性
   │  ├─ 仲裁后写 final 键
   │  └─ annotator_source=HUMAN_GOLD / LLM_SILVER 合流
   ▼
corpus_spans_annotations 表 → 模型微调（SFT）+ 系统情感雷达 + 论文统计
```
