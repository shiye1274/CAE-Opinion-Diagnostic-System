【这是什么】
你要做的标注任务的所有文件。你在这台电脑上装一个免费开源的标注工具
（Label Studio），离线标注，完成后把导出的 JSON 文件发回给队长即可。
不需要连任何服务器，不需要注册任何账号（账号在本地自己建）。

【第一步：安装（一次性，约 5 分钟）】
1. 装 Python 3.10 或以上：https://www.python.org/downloads/
   安装时务必勾选 "Add Python to PATH"
2. 打开命令行（Win 键搜 cmd 或 PowerShell），执行：
   pip install label-studio -i https://pypi.tuna.tsinghua.edu.cn/simple
   （用清华镜像，国内快；看到 Successfully installed 即成功）

【第二步：启动（每次标注前执行）】
命令行执行：
   label-studio start
第一次会让你在浏览器（自动打开 http://localhost:8080）注册：
   → 随便填邮箱 + 设个密码（纯本地，不会发邮件，也不会泄露）
   → 进入主界面

【第三步：导入任务（一次性，约 2 分钟）】
1. 左上角 Create → 项目名填：GreenSilk 校准集
2. 进入项目 → Settings → Labeling Interface → 选 Code 标签
3. 把本包里 label_config.xml 的全部内容粘贴进去 → 点 Save
4. 回到项目页 → Import → 选择本包里的 calibration_set.json → 导入
   （完成后列表里出现 C001、C002… 任务卡片 = 成功）

【第四步：开始标注】
1. 先读《标注入门指南.md》（重点：5 个核心字段 + 四条阿语准则 + 10 个练习）
2. 点开任务 → 左边读原文 → 右边按顺序打 8 个字段 → Submit
3. 不确定就 Skip，不要瞎标；命中"文化误读"必须高亮证据句并抄录
4. 每天标多少都行，进度自动保存在本地
5. 红线：不要把你的标注结果给另一位标注员看（双盲要求）

【第五步：完成后回传（最重要！）】
1. 全部（或阶段性）标完后：项目页 → Export → 选 JSON → 下载
2. 把下载的文件重命名为：ann_你的名字.json
3. 通过微信/QQ 发给队长
   → 队长用脚本自动计算两人一致性（Kappa），不需要你做任何统计

【常见问题】
- 命令提示"不是内部或外部命令" → Python 没勾 PATH，重装或重启命令行
- 8080 打不开 → 看命令行窗口是否报错，截图发队长
- 阿语显示方块 → 换 Chrome 或 Edge 浏览器
- 提交按钮灰色 → 有必填字段没选完（主导框架/情感/误读）
- 想改已提交的 → 找队长处理，不要自己删任务
- 装不上/报错超过 20 分钟 → 截图发队长，别硬折腾
