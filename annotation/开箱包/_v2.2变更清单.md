## 二、改了什么（3 处规则 + 2 个选项）

### 🔴 改动 1（R1）：没提中国品牌时，情感必须标 0

| | 内容 |
|---|---|
| **旧规则**（矛盾） | 指南正文说"没提中国品牌标 0"，但**例题 2 给了 +2、例题 4 给了 -1、例题 10 给了 -1** |
| **新规则**（v2.2 唯一标准） | `role_type = NOT_APPLICABLE 未提中国品牌` → **情感必须 = 0 客观中立** |
| **为什么** | 情感字段定义是"**针对中国品牌**的情感"。没有中国品牌 = 没有评价对象 = 0 |
| **判断口诀** | **先定 role_type，是"未提中国品牌"就直接情感=0，不用纠结** |

> ⚠️ 反过来：如果你觉得**必须**给非 0 情感（文中确有对中国车的褒贬），说明 `role_type` 选错了——回去改成主角/顺带提及，再正常标情感。

**例题已同步修正**：例题 2、4、5、10 的答案都改成 0 了（改的地方标了 🆕）。

---

### 🔴 改动 2（R2）：品牌矩阵与角色必须自洽

| | 内容 |
|---|---|
| **新规则** | 选了 `NOT_APPLICABLE 未提中国品牌` 时，`brand_matrix` 里**不能出现中国品牌** |
| **合法情况** | 文中只有 Tesla/丰田/现代起亚等**外国**品牌 → 可以选 NOT_APPLICABLE，矩阵照填这些外国品牌 ✅ |

| **判断口诀** | **先看 brand_matrix 有没有中国品牌，再定 role_type** |

## 四、进度不一致怎么办？

**完全不影响。** 原因：

| 担心 | 实际情况 |
|---|---|
| "我标得慢，规则变了怎么办？" | 规则是**判断口径**，不是字段结构。你之前标的 99% 有效，只需按上表回改 8 条 |
| "两人标到不同位置，能算一致性吗？" | 能。一致性只算**两人共同标过的条目**，进度快慢不影响 |
| "我按新规则，对方按旧规则？" | 不会——两人都会收到这份清单，规则已统一 |
| "改了配置，我之前的标注会丢吗？" | **不会**。只是新增选项和字段，原有字段、选项、顺序全部不变 |

**建议**：两人**都在回改完/读完本清单后再继续标**，保证从同一起跑线开始。
