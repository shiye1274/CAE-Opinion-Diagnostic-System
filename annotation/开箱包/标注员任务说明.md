## 📋 任务流程（每人相同）

```
1. 装 Label Studio（使用说明.txt 第一步，约 5 分钟）
2. 读《标注入门指南》+ 做 10 个练习对答案（约 1 小时）
3. 导入配置和任务（使用说明第三步，约 5 分钟）
4. 开标：从 C001 开始按顺序标（建议每天 50–100 个，约 7–10 天完成）
5. 完成后 Export → JSON → 文件重命名发回队长
```

## 🆕 v2.2 更新：按你的进度对号入座（重要）

规则改了 3 处，但**你之前标的 65 条 99% 有效**。先看 `_v2.2变更清单.md`，然后按情况做：

| 你的情况 | 要做什么 | 耗时 |
|---|---|---|
| **还没开始标** | 什么都不用做，直接按 v2.2 指南标 | 0 |

**两条新口诀（背下来）**：
1. 情感：`未提中国品牌 → 情感 = 0`
2. 角色：`先看品牌矩阵有没有中国品牌，再定 role_type`

**两人进度不同完全不影响一致性计算**——只算两人共同标过的条目。

## 📤 交付物（交什么）

**只需交 1 个文件**：
- 标完（或阶段性标完）后，Label Studio 项目页 → **Export → JSON**
- 重命名为 **`ann_你的名字.json`**（如 `ann_小丽.json`）
- 微信发给队长。**不用做任何统计**——一致性（Kappa）由队长脚本自动算。

## ⚠️ 五条纪律（破坏了数据就不能用）

1. **两人独立标**：不讨论、不给对方看你的标注、不看对方进度（双盲要求）
2. **看不懂就 Skip**：不确定的标 CANNOT_DETERMINE + 备注，**不要瞎猜**
3. **命中"文化误读"必须做两件事**：原文高亮证据句 + 下方文本框抄录
4. 任务按顺序标，**不要跳着标**（保证抽样顺序）
5. 遇到报错/页面问题：截图发群里，**不要自己折腾超过 20 分钟**

## ❓ 常见问题

- **要交几份？** 一个人 1 个 JSON 文件。中途想分批交也可以（比如标满 300 个先交一版）。
- **进度会丢吗？** 本地自动保存，但建议**每 2 天手动 Export 一次**备份发自己微信。
- **要联网吗？** 装软件和启动时要，之后标注完全离线。
- **阿语看不懂的词**：查《指南》"常见疑问速查表"；实在不懂 → Skip + 备注。
- **谁先标完谁吃亏吗？** 不会——两人标同一批任务，先后无影响。
