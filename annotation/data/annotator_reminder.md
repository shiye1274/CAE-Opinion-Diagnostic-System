# 给标注员的微信提醒文案

> 可直接复制到微信发送给两位标注员。

---

各位标注员好！

项目当前卡在人工标注环节，急需大家配合推进。

请大家尽快完成 Label Studio 中“GreenSilk 校准集”的标注任务，并按以下步骤导出：

1. 打开 Label Studio → 选择项目“GreenSilk 校准集”
2. 点击顶部菜单【项目 / Project】
3. 选择【Export】
4. 格式选【JSON】
5. 点击【Export】下载
6. 将文件命名为：`ann_你的名字.json`
   （例如：ann_张三.json、ann_李四.json）

导出后请直接把文件微信发给我（队长）。

建议截止时间：今明两天内。

标注规范以 `annotation/guidelines/标注入门指南.md` 为准，遇到边界案例请标记 CANNOT_DETERMINE 并写备注，不要硬猜。

收到后我会自动跑一致性检验，多谢配合！
