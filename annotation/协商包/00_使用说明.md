## 📐 三处核心阈值差异（草案已给规则）

### 1. 情感标尺（19 处分歧）
```
+2 强烈推崇:   标注员1 = 0 次    裘鑫 = 8 次   ← 1号从不用 +2
-1/-2 负向:    标注员1 = 4 次    裘鑫 = 0 次   ← 裘鑫从不用负向
0 客观中立:    标注员1 = 39      裘鑫 = 39     ← 唯一一致的
```
→ 草案：**+2 只给"最高级/定义性赞美"，-2 只给"抵制级负面"，其余按强度分档**

### 2. 主导框架（34 处分歧）
```
MARKET_COMPETITION:  1号=20  裘鑫=4    ← 1号偏爱 5 倍
LOCALIZATION_INVEST: 1号=1   裘鑫=7    ← 裘鑫偏爱 7 倍
OTHER 其他:          1号=11  裘鑫=20   ← 裘鑫爱用"其他"
```
→ 草案：**先问"文章在讲什么动作"，OTHER 必须先排除具体框架**

### 3. 文化误读（10 处分歧）
```
CANNOT_DETERMINE:  1号=5  裘鑫=0    ← 只有1号用
NO_MISREADING:     1号=47 裘鑫=56   ← 裘鑫 98% 全选"无误读"
```
→ 草案：**观点=无误读；可验证的虚假断言=事实错误；信息不足=无法判断**

## ❓ 常见问题

**Q：我改了，对方没改，κ 还是不达标怎么办？**
A：κ 算的是**两人共同标注的交集**。必须**两人都改**才有效。所以第 2 步（互发 Q1–Q10 答案）很关键。

**Q：讨论时发现草案规则不对，能改吗？**
A：能，而且**鼓励改**——草案就是让你们提意见的。把修改意见写在 Q 后面，我汇总成正式 v2.3。

**Q：要改多少条？**
A：只改**有分歧的字段**。57 条里完全一致的部分不用动。预估 1–2 小时/人。

**Q：改完还要重新标一遍吗？**
A：不用重新标全部，**只修正分歧处**。

**Q：κ 一定能到 0.78 吗？**
A：按经验，统一标准后可达 **0.65–0.78**。机械修复上界是 0.569，剩下靠这轮讨论。如果最后仍差一点，队长会如实报告并说明原因——**但先尽力对齐**。
