## 二、🔴 问题 1（配置级，最严重）：`gulf_dialect` 控件根本不存在

```
gulf_dialect 字段缺失 65/65 (100%)
labelstudio_config.xml 中搜 gulf_dialect / dialect / lang_variant → 无任何控件
```

**这不是标注员漏标，是我们的 Label Studio 配置里压根没放这个控件。**

影响：**创新点①「海湾方言情感计算」的方言标签源头断了**——标注员无法标，κ 也算不了方言维度。

**修复方案（二选一）**：
- **方案 A（推荐，不打扰标注员）**：方言维度改由规则+模型自动打标（正则匹配海湾方言词表，如 `والله` / `يوصل` / `خوش`），人工只标情感与框架。在论文中如实写"方言维度为自动标注，人工标注覆盖情感/框架/角色"。
- **方案 B**：加控件后让两位补标方言字段（多花 20 分钟，但字段真实）。

**建议走 A**，理由：方言识别本身是模型创新点，用规则打底反而能形成"规则 baseline vs 模型"的对比实验。

## 三、🟡 问题 2：15 处逻辑矛盾（仲裁时需修正）

### 3a. 「未提中国品牌」却填了品牌矩阵 —— 8 处

| 条目 | 矛盾内容 |
|---|---|
| C011 | role=未提品牌，brand_matrix=**BYD 比亚迪** |
| C023 | role=未提品牌，brand_matrix=**Hyundai/Kia** |
| C040 | role=未提品牌，brand_matrix=**Tesla** |
| C043 | role=未提品牌，brand_matrix=**Ceer** |
| C045 | role=未提品牌，brand_matrix=**BYD\|Tesla** |
| C048 | role=未提品牌，brand_matrix=**Hyundai/Kia** |
| C052 | role=未提品牌，brand_matrix=**Haval/GWM** |
| C063 | role=未提品牌，brand_matrix=**Ceer\|MG** |
| C065 | role=未提品牌，brand_matrix=**Hyundai/Kia\|Tesla** |

**根因**：标注员理解的"未提中国品牌"=「不是中国品牌主角」，而 role_type 的语义是「文中没出现中国品牌」。**语义歧义，指南需澄清**。

**处理**：κ 计算时这 8 条在 `brand_role × brand_matrix` 上必然与标注员2 冲突——**这正是 κ 的价值**，进仲裁队列由你裁定。

### 3b. `brand_matrix` 用了自由文本 —— 7 处

C016 / C019 / C022 / C025 / C033 / C050 填了 `其他(备注栏写)` 而不是标准选项。

**根因**：`brand_matrix` 是多选控件，标注员想写"其他"但控件没这个选项，只能手打。

**处理**：给 `brand_matrix` 增加 `OTHER 其他` 选项（下次标注用），本批这 7 条进仲裁时人工归类。

### 3c. 「未提品牌」却给了非中立情感 —— 5 处（需指南澄清）

C011(+1) / C021(-2) / C022(+1) / C031(-2) / C033(+1)

**语义问题**：文中没中国品牌，情感是评谁的？可能是评**国家/政策/其他国家品牌**。

**处理**：指南需定义"情感对象"——建议明确为"**对文中所涉主体的整体情感倾向**"，或要求未提品牌时情感强制为 0。**这一条必须在标注员2 导出前定下来**，否则两人标准不一致会拉低 κ。
